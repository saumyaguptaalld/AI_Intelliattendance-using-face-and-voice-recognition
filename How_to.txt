# in voice_recognition.py
Capture student voice: Record a short, clear speech sample.
Generate voice embedding: Resemblyzer converts speech into a 256-dimensional vector.
store in Supabase: Save the vector in students.voice_embedding.
Verify identity during attendance: Compare the new voice embedding against the enrolled student's embedding. 

# resemblyzer package: Python package by Resemble AI designed to analyze, extract, and compare voice characteristics from audio
operates on both CPU and GPU, optimized primarily for english(run fast on hardware like NVIDIA GTX 1080)
Used in speaker verification, fake speech detection, feature extraction 
# librosa is for audio processing utilizes dsp intead of DL

if similarity score > best_score update best_score and best_sid, further after all students are checked , see if scores are greater thn threshold, return best_sid and best_score and if not then return just best_score and none as student id

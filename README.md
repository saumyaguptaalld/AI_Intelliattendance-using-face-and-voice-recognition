# AI_Inteliattendance-using-face-and-voice-recognition
AI_Inteliattendance is an AI-powered attendance management app built with Streamlit. It provides teacher and student portals, using face recognition on class photos and voice recognition on audio to help record attendance. Supabase stores user(student and teacher), subject, enrollment, and attendance data. The project also uses bcrypt for password hashing, dlib and scikit-learn for face processing, Resemblyzer and librosa for voice processing, and Segno for QR code sharing.
